💊 Pharma Chatbot – Project Description

The Pharma Chatbot is an AI-powered educational assistant designed to support students, pharmacy learners, and healthcare professionals by providing accurate and easy-to-understand information related to pharmaceutical sciences. The chatbot interacts with users through a conversational interface and responds to queries in real time.

The system is built using Flask for the backend and integrates a Large Language Model (LLM) via the Groq API to generate intelligent and context-aware responses. It focuses on core pharmacy domains such as pharmacology, pharmaceutics, pharmaceutical chemistry, dosage forms, drug mechanisms of action, side effects, and drug interactions (theoretical).

To ensure safety and ethical use, the chatbot is strictly designed for educational purposes only. It does not provide medical diagnoses, prescriptions, or treatment plans and always encourages users to consult qualified healthcare professionals for medical decisions.

The chatbot features a clean and user-friendly web interface developed using HTML, CSS, and JavaScript, enabling smooth communication between the user and the AI assistant. This project demonstrates the practical application of AI in pharmaceutical education and highlights how conversational AI can enhance learning, reduce information barriers, and support academic and career guidance in the pharma domain.

AI-powered pharma knowledge assistant
